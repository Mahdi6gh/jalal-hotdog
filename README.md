# سایت «هات‌داگت رو خودت بساز» — جلال

## اجرا
- ساده‌ترین راه: `index.html` را در کروم باز کنید (فونت‌ها از اینترنت لود می‌شوند).
- برای تست مثل سایت واقعی، با یک سرور محلی باز کنید:
  ```
  npx http-server site -p 5173
  ```
  و بروید به http://localhost:5173

## ساختار
| فایل | کار |
|---|---|
| `index.html` | ساختار صفحه |
| `styles.css` | ظاهر، رنگ‌های برند، نسخه‌ی موبایل |
| `app.js` | انیمیشن‌ها (GSAP)، صداها، قیمت، فیش |
| `config.js` | **منو، قیمت‌ها، تلفن، آدرس، صداها** — برای تغییرات معمولی فقط همین را ویرایش کنید |
| `assets/img` | عکس‌های دوربُری‌شده (WebP) |
| `assets/img/layers` | لایه‌های تاپینگ و سس که روی هات‌داگ می‌نشینند |
| `assets/sfx` | صداها |

## نکته‌ها
- قیمت **گوجه** و **بیکن و پارمسان** در منوی شما نبود؛ قیمت نمونه گذاشته شده (در `config.js` با `sample: true` مشخص است).
- نوشیدنی‌ها «قیمت را بپرسید» هستند؛ در فیش «استعلام» نوشته می‌شود. برای قیمت‌دار کردن، `price` را در `config.js` عدد بگذارید.
- عوض کردن صدا: یکی از فایل‌های پوشه‌ی `sounds` (صفحه‌ی `sounds/sound-test.html`) را با همان اسم در `assets/sfx` کپی کنید.
- اسکریپت‌های ساخت لایه‌ها و دوربُری در پوشه‌ی `tools` هستند (برای وقتی که عکس جدید اضافه شود).
